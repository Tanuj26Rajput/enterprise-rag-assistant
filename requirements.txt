# Direct dependencies, pinned to the versions this project is developed and
# tested against. Transitive dependencies are left to pip's resolver.
#
# Why pin at all: an unpinned requirements file means a rebuild six weeks from
# now installs different code than the build that was tested, and the first
# anyone hears of it is a failure in production. Why pin only the direct set:
# a full lock file (pip-compile, uv, Poetry) is the right answer for a team,
# but it must be generated on the target platform, and the versions below are
# the ones actually exercised here. See docs/environment.md.
